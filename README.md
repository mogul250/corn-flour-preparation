# Corn-Flour-preparation-management-system
this system will be working on all actions which are carried out during corn preparation until it is deployed and delivered to the consumers,
these actions include:
    - corn supply management
    - corn preparation (phase 1) management
    - corn preparation (phase 2) and packaging system 
    - corn flour dustribution system 
    - all inventories management system
    - report generation system
# HOW TO USE CORN FLOUR PREPARATION MANAGEMENT SYSTEM
start the system all you need is a computer and internet (and node.js runtime pre-installed on your computer)
# build commands
to install frontend dependecies you need to change the directory from initial directory to the front-end directory
with the following command:
    - cd front-end
    - npm i
to install the backend dependecies all you need is simply to run the following command:
    - npm i
# start commands
to start the application you need two different terminal tabs (one for front nd and the other one for backend)
 1. front end:
    i. ....
 2. backend:
    - npm run dev
